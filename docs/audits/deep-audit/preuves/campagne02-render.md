## Carte des parcours

1. Document → MPRenderer.parseOptions + copie Markdown → queue série → MPPreprocessMarkdown → Hoedown + callbacks HTML/TOC → résultat immutable → génération vérifiée sur main queue → publication des offsets/Markdown/token → composition styles/scripts/template/CSP → MPDocument WebView load ou body replacement. La génération invalide les opérations annulées déjà dispatchées ; rendererLoading est pollé sans bloquer le main thread. Le parse synchrone emprunte la même transformation pure mais ses appels headless doivent rester isolés des publications UI.
2. Tâches : offset UTF16 du texte original (+ front matter) injecté avant CRLF normalisé → marqueur UUID sans collision → callback listitem extra → checkbox index et offset enregistrés dans le même ordre → tasklist.js ajoute token → MPDocument vérifie token, égalité source snapshot, index/offset/range puis applique toggle. Les callbacks des listes imbriquées peuvent être produits avant le parent : le mapping porte l'indice HTML explicite, pas l'ordre visuel. Les markers de code/tâche sont retirés avant escaping du code, puis nettoyage HTML final.
3. HTML export → même currentHtml → options embed styles/Prism/scripts diagrams/MathJax → MPAsset/HBHandlebars → Default.handlebars. Variations légitimes : absence CSP export, JS autonome diagrammes, aucun table-resize/task bridge ; accessoire Custom reste une fonction d'aperçu dans ce pipeline. Pas de seconde sémantique Markdown divergente.
4. PDF → MPDocument original WebView/JSContext/génération/DOM+CSSOM/printinfo capturés → impression originale privée → seconde impression métadonnées sur le même preview, href marqueurs et géométrie headings → MPPDFAnchorInjector compare nombre pages/MediaBox/rotation/rects, refuse source absente ou ambiguë avant modification → GoTo sur annotations originales → dataRepresentation atomique → restitution DOM/règles/media + cleanup. Original publié, métadonnées jamais publiées. Source/heading distincts identifiés par prefix UUID + grammaire stricte. Targets inconnus ne créent pas de destination arbitraire. Tests de pixels/réouverture PDF/génération existants relus mais pas exécutés par cet agent : restent gates root.
5. Quick Look → fichier UTF8/autodetect/Latin1 → normalisation CRLF → préprocesseur partagé et callbacks partagés → wrapper propre + CSS intégrée → WKWebView scripts désactivés + CSP scripts/connect/frame/object none → completion après navigation propre, remplacement annule ancien handler et callbacks anciens ignorés. Le nil baseURL limite accès sandbox aux ressources ; les images relatives voisines ne sont pas promises comme accessibles par ce test. QuickLook exclut TOC/smartypants/diagrammes/MathJax/Prism JS par contrat, légitime. Différences lookup assets : app support du host contre vrai home getpwuid_r du sandbox ; elles nécessitent leurs protections/entitlements dédiés. A2-R03 corrige une divergence accidentelle du wrapper couleur.
